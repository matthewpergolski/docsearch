The table is measured per file type on the public test set. The three large numbers weight it by your shares. Each file type comes from one source, so read this as a guide. For Word, PowerPoint, Excel and CSV the test only knows the right file, so any piece of that file counts as a hit, even one from the wrong section. PDF is scored on the exact page, which is harder.

2. Which pipeline suits this mix?

Each bar is one way to build the search, scored for your mix. Click one to see its numbers above.

Measure:

The text embedding model is Qwen3-Embedding-0.6B, except in the pipelines named for mxbai (mxbai-embed-large-v1) and for EmbeddingGemma 2 (google/embeddinggemma-2; in the one-model pipeline it also embeds the page pictures). The reranker is gte-reranker-modernbert-base. Every pipeline searched the whole test folder, slide images included. nDCG@10 is a 0 to 1 ranking score: full credit when the right result is first, less the lower it sits, none outside the top 10.
